# Tiles and progress rings

The Atelier shows only the boxes you are working on.

## One row per unit, one tile per model

Tap a tile to open the model and start work.

## Reading the rings

Each ring has two halves: one for assembly, one for painting.

| Ring | Meaning |
|---|---|
| Outline | In progress |
| Solid | Done |

## Running work stays visible

A running timer marks its tile, and a **Session** row at the top takes you straight back to it.
