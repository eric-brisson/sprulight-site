# Start a session

Assembly and painting are timed separately, and every model keeps its own time.

## Start

1. In the [Atelier](/atelier/tiles-and-rings), tap a model's tile.
2. Start assembly (or painting) from the model. A clock runs.

## While it runs

- **Pause** when you step away, and **resume** when you are back.
- On iPhone, the timer sits on your Lock Screen and in the Dynamic Island, so you can pause, resume or stop without opening the app.
- The session carries on while the app is closed.

## Forgot to start the timer?

Add the time by hand from the model.

::: tip
Not sure how to end a session? See [Stop vs Finish](/assembly/stop-vs-finish).
:::
