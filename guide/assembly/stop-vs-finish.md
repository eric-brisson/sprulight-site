# Stop vs Finish

Both end a session. They differ in what happens to the model.

| | Saves the time | Marks the stage complete |
|---|---|---|
| **Stop** | Yes | No |
| **Finish** | Yes | Yes |

## Stop

Use **Stop** when you are done for now but the stage isn't. The time is saved and the model stays in progress.

## Finish

Use **Finish** when the stage is done. For assembly, the model is marked assembled. For painting, it is marked painted.
